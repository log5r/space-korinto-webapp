# Space Korinto

[English](README.md) | **日本語**

鋼の筐体に組まれた、ハンドルひとつで遊ぶ宇宙の盤面。銀の玉をレールから打ち上げ、ピンの小惑星帯と惑星バンパーの間を落として、ワームホールに吸い込ませます。下の自動フリッパーが落ちてきた玉を打ち上げ、もう一度チャンスをくれます。持ち玉 30 個の **ノーマルモード**、90 秒の **タイムアタック**、制限のない **無限モード** があります。
HTML / CSS / JavaScript (Canvas 2D + Web Audio API) のみで書かれており、ビルドや依存パッケージは不要です。[Easy Block Breaker](https://github.com/log5r/EasyBlockBreakerWebapp) の延長として作られており、筐体・HUD・玉の質感は共通です。コリントゲーム／スマートボール／ピンボールを混ぜ、Windows 3D ピンボールの宇宙のエッセンスを添えています。

画面の言語はブラウザーの優先言語から日本語・英語を自動選択します。どちらも含まれない場合は英語を表示します。

## 遊び方

- タイトル画面でモードを選びます。
  - **ノーマルモード**: **持ち玉 30 個** からスタート。1 発ごとに 1 個消費し、ワームホールに入ると賞球が戻ります。持ち玉が尽き、盤面の玉がすべて落ちたら終了です。
  - **タイムアタック**: 玉は無限、**90 秒** の制限時間。延長なしの90秒固定です。
  - **無限モード**: 玉も時間も無限（TIME 欄は経過時間）。ポーズ画面の「スコアを確定して終了」でリザルト画面へ進みます。
- 操作は下の壁にある **青く光るハンドルゲージ** だけ。ハンドルを回している間、玉はノーマルで毎分 100 発、タイムアタック・無限モードで毎分 200 発の自動連射。いちばん左（STOP）に戻すと発射が止まります。弱いと上部アーチの左側に、強いと右側に落ちます。
- 得点（すべて倍率がかかります）:
  | ターゲット | 得点 | 賞球（ノーマル） |
  | --- | --- | --- |
  | ワームホール・シアン（2 か所） | 200 | 1 個 |
  | ワームホール・パープル（2 か所） | 500 | 2 個 |
  | ブラックホール（中央） | 1,000 | 4 個 |
  | 惑星バンパー（3 つ） | 100 | — |
  | スリングショット（2 つ） | 50 | — |
  | インレーンの星（2 つ） | 300 | — |
  | ハイパースペース・レーン | 300（点灯済みは 100） | — |
- 上部の **ハイパースペース・レーン** 3 本をすべて通過すると 1,500 点と、以降の **倍率 +1**（最大 ×5）。発射の強さごとに入りやすいレーンが決まるので、3 本揃えるには狙いを変える必要があります。
- **フリッパーは自動** で、上の捕捉ゾーンに玉が落ちてくると振ります。フリッパーの間や外側のレーンに落ちた玉はアウト。速く上昇中の玉はワームホールを飛び越え、落ちてくる玉やゆっくりの玉だけが吸い込まれます。
- ベストスコアはモードごとにブラウザの `localStorage` に保存されます（前回選んだモードも記憶されます）。
- スコアの上限は `Number.MAX_SAFE_INTEGER`（9,007,199,254,740,991）です。到達した場合はそこで得点が止まり、「SCORE LIMIT」画面のあとタイトルに戻ります。

- **無限モードの宇宙演出**: 玉は約1.25秒で消える色付きの光の軌跡を残し、惑星バンパーに当たると色が変わります。32秒周期で重力の渦が発生し、中央ディスプレイが4秒前から予告します。8秒間、近くの玉を引き寄せて旋回させ、2秒かけて解放します。渦の位置と回転方向は周期ごとに変わり、ポーズ中は演出も停止します。光の軌跡はメインメニューとポーズメニューの「ボールの光の軌跡」でオン／オフを切り替えられ、設定は保存されます。

- **ノーマル・タイムアタック：振り分けゲート**が中段で10秒ごとに左右へ傾き、玉の流れを変えます。切り替え2秒前に予告し、1.5秒かけて傾きます。盤面の表示に合わせ、左は弱め・右は強めに打ち分けてください。ゲートの可動域のピンは両モードで取り除かれます。ノーマルは点灯側が通常配当、反対側は得点半分・賞球なしです。タイムアタックは点灯側の左右ワームホールの得点2倍、反対側は通常得点（上部レーンの倍率も掛かります）。切り替え直後の1秒は両側2倍です。中央ブラックホールは常に通常配当です。

### 操作

| 操作 | 入力 |
| --- | --- |
| ハンドル | 盤面上のマウス / タッチの横位置、または <kbd>←</kbd> <kbd>→</kbd> / <kbd>A</kbd> <kbd>D</kbd> |
| スタート / リトライ | <kbd>Space</kbd> / <kbd>Enter</kbd> または画面のボタン |
| ポーズ / 再開 | <kbd>P</kbd> / <kbd>Esc</kbd> または右上のボタン（タブを隠すと自動ポーズ）。ポーズ画面からスコア確定終了・やめるも選べます |
| ミュート切替 | <kbd>M</kbd> または右上のボタン |
| 音量 | タイトル画面・ポーズ画面のスライダー（`localStorage` に記憶） |

## 実行

`index.html` をブラウザで開くだけで動きます。

ローカルサーバーで配信する場合:

```bash
python3 -m http.server 8765
```

http://localhost:8765/ を開いてください。

## テスト

ルールと物理は Node でヘッドレスに検証できます（依存なし）:

```bash
for t in tests/i18n.cjs tests/modes.cjs tests/board.cjs tests/score-limit.cjs tests/gate.cjs tests/timed-lanes.cjs tests/infinite.cjs; do node "$t" || break; done
```

タイムアタックの比較は `node scripts/check-balance.cjs --timed` で実行できます（90秒固定、各戦略6条件）。

ノーマルの難易度の比較は `node scripts/check-balance.cjs` で再現できます。乱数条件6種類・各180秒上限で、中央固定、弱打ち固定、予告に合わせた打ち分けのプレイ時間・得点・1発あたり賞球を比較します。

## Cloudflare へのデプロイ

Node.js 22 以降と Cloudflare アカウントが必要です:

```bash
npx wrangler@4.131.1 login
npx wrangler@4.131.1 deploy
```

`wrangler.jsonc` が `space-korinto` Worker を設定します。デプロイ時に `scripts/prepare-deploy.cjs` がゲームのファイルとライセンスだけを `dist/` にコピーし、`workers.dev` の静的アセットとして公開します。

## 構成

```
index.html        タイトル / ポーズ / リザルトのオーバーレイ
css/style.css     オーバーレイのスタイル（Easy Block Breaker より）
js/core.js        定数: 筐体の寸法、発射の強さ、得点、賞球、フリッパーのタイミング
js/i18n.js        日本語 / 英語の辞書
js/audio.js       合成効果音
js/board.js       盤面レイアウト: ピン、レーン、バンパー、ワームホール、スリングショット、フリッパー、発射レーン
js/renderer.js    筐体・HUD・玉の描画（Easy Block Breaker より）と宇宙の盤面
js/game.js        ルール、モード、自動フリッパー、物理、入力、ループ
tests/*.cjs       ヘッドレスの検証
design/           盤面デザインの元になった静止カラーモック
```

### タイムアタックの狙い分け

タイムアタックの上部は、ピンで散る前に玉を分ける3本のガイドです。左は弱め、中央は約45〜55％、右は約65％を目安に狙えます。レーンは下向きに横切ると点灯し、境界での細かな往復は重複加点しません。3本で倍率＋1（最大×5）は従来どおりです。

比較結果と採否は [調整レポート](design/balance/report.md) にまとめています。`node scripts/validate-timed-balance.cjs` は選定に使わなかった乱数条件で固定打ち20段階と操作戦略を比較します。
